# FTS TVA - Trouver et Completer les Numeros de TVA Manquants

Bienvenue ! Ce guide vous explique comment utiliser notre outil pour retrouver automatiquement les numeros de TVA francais manquants dans vos fichiers FTS (Financial Transparency System).

## C'est quoi l'objectif ?

Vous avez un fichier Excel avec des beneficiaires francais, mais certaines lignes n'ont pas de numero de TVA.

Notre outil fait ca pour vous :

1. Cherche le numero de TVA en utilisant le nom et l'adresse du beneficiaire
2. Complete automatiquement la colonne VAT number of beneficiary
3. Colore les lignes modifiees pour que vous voyiez clairement ce qui a change
4. Genere un rapport avec tous les details (TVA trouve, confiance, strategie utilisee, etc.)
